Centro Aiuto Blocchino

Tutto quello che devi sapere per utilizzare al meglio Blocchino v2.0.0.

🚀 Guida Rapida

  • Avvio: Una volta scaricato il file .exe, fai doppio clic per aprirlo. Blocchino è "Portable", non sporca il tuo registro di sistema!
  • Scrittura: Digita i tuoi testi liberamente. L'interfaccia è pulita per favorire la tua concentrazione.
  • Salvataggio: Usa il menu interno per esportare in formato standard .txt.

❓ Domande Frequenti (FAQ)

D: L'antivirus segnala il file come "non sicuro". Perché?
R: È un falso positivo comune per i software nuovi e indipendenti. Essendo Blocchino un progetto Open Source di SAFFDDS, puoi stare tranquillo: il codice è trasparente e sicuro. Clicca su "Esegui comunque".
D: Blocchino v2.0.0 funziona su Linux o Mac?
R: Attualmente la v2.0.0 è ottimizzata per Windows. Tuttavia, stiamo esplorando la compatibilità cross-platform per le future release!
D: Ho trovato un bug, cosa faccio?
R: Segnalalo immediatamente! Il feedback degli utenti è un vanto per noi. Puoi farlo tramite il repository GitHub.
